### Built-in Referral campaign

The built-in Referral campaign sits beside the existing referral flow. Successful
referrals are projected into replay-safe campaign fulfillments without changing the
contract call, points logic, or existing referral APIs. Current users can read their
status through `GET /api/campaigns/:idOrKey/fulfillments/me`; see [API.md](./API.md#campaigns).
